# 📊 Customer Churn Analysis Dashboard

## 📌 Overview

An interactive Power BI dashboard built using the IBM Telco Customer Churn Dataset to analyze customer churn, identify key churn drivers, measure business impact, and support data-driven customer retention strategies. The IBM sample dataset represents a fictional telecom company and is widely used for churn analytics.

## Dashboard Features
- 📊 Executive-level interactive dashboard with business storytelling
- 📈 Dynamic KPI cards for key business metrics
- 🔍 Drill-down to explore data across hierarchical levels
- 🎯 Drill-through to a Customer Churn Analysis page for detailed customer-level        investigation
- 🎛️ Interactive slicers and filters for dynamic report exploration
- 🔄 Cross-filtering and cross-highlighting between visuals
- 🔖 Bookmarks for guided navigation and enhanced user experience
- 🧭 Page navigation buttons for seamless movement between dashboard pages
- 💡 Dynamic insight panel highlighting key business findings
- 📱 Clean, executive-focused, responsive dashboard layout

## 🛠️ Tech Stack
- Power BI
- DAX
- Power Query
- Excel
- pandas
- MySQL
