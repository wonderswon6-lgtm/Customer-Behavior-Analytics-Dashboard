# Data Analyst Projects

A collection of end-to-end data analytics projects covering real-world business problems — from raw data to interactive dashboards and actionable insights.

---

## 🗂️ Projects

### 1. [Customer Behavior Analysis](./data%20analyst%20projects/customer%20behavior%20analysis/)
Analyzes retail customer shopping behavior across 3,900 transactions to uncover purchasing patterns, demographic trends, product preferences, and subscription adoption.

| | |
|---|---|
| **Tools** | Power BI, SQL, DAX, Power Query, Excel |
| **Dataset** | 3,900 rows × 18 columns (CSV) |
| **Deliverable** | Interactive Power BI dashboard |

---

### 2. [Smytten Supply Chain Analysis](./data%20analyst%20projects/smytten%20supply%20chain%20analysis/)
End-to-end supply chain analysis for Smytten (D2C beauty & personal care) covering 100 SKUs — supplier evaluation, logistics efficiency, inventory management, and defect tracking. Completed as a client project during an internship at [Datamites](https://datamites.com/).

| | |
|---|---|
| **Tools** | Power BI, Excel, PowerPoint |
| **Dataset** | 100 SKUs across 3 product categories (CSV) |
| **Deliverable** | Power BI dashboard + presentation deck |
